# 综测手记：数据与隐私

本说明对应当前 Android 源码，不代表尚未实现的功能。

- 活动记录、学年成绩、历史评分库、导入映射和证明图片保存在设备本地。
- 当前应用未声明 Android 网络权限；活动匹配在本机执行。
- 选择导入表格、照片或活动包时，应用读取用户选择的内容。保存的证明图片会复制到应用私有目录。
- 导出 Excel、备份或分享活动包时，用户选择内容及保存位置或接收应用。导出的文件可能包含成绩、活动信息及照片；接收方对数据的处理由对应应用负责。
- 应用关闭 Android 自动备份。卸载会移除应用私有数据；卸载前应自行导出需要保留的数据。已导出到应用外的文件不会随卸载一并删除。

公开截图和样例请使用虚构数据，不要包含真实姓名、学号、成绩、聊天内容或证明照片。
