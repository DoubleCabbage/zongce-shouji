# 综测手记

给同学用的校园活动与综合素质测评记录工具。记录参加过的活动、整理证明图片、查看往年参考分数，并导出 Excel 申报表。

支持 Android 8.0（API 26）及以上版本。当前源码版本为 0.3.0；评分规则按现有实现测算，使用前请核对自己学校当年的规则。

应用名称为「综测手记」，图标为记事本与勾选符号。图标矢量源文件与 PNG 位于 [docs/branding](docs/branding)。发布准备见 [发布说明](docs/PUBLISHING.md)，数据处理方式见 [隐私说明](docs/PRIVACY.md)。

原生 Android 项目。使用 Kotlin 和 Jetpack Compose，个人记录、历史评分库与证明图片保存在设备本地。

## 用 Android Studio 打开

在 Android Studio 选择 **Open**，打开本目录，等待 Gradle 同步，再运行到模拟器或 Android 手机。需在 **SDK Manager** 安装 Android 35 平台和 Android SDK Build-Tools 35，并确认 SDK 许可协议。首次同步可能需要下载尚未缓存的组件。

## 当前可验收功能

- 首页可切换学年（9 月至次年 8 月），显示综合素质成绩测算和六维活动进度。活动分按本学年参与、重复核对结果及领域上限计算：身心健康活动 10 分，思想成长与学术创新各 14 分，劳动与美育各 12 分，组织协调能力 8 分。点击维度可查看对应记录。
- 新建记录时填写活动、维度、职务或等级、参考估分，并创建第一次参与。
- 在记录详情中追加参与次数；每次参与可写日期、说明并添加多张证明图片。
- 同一活动在同一学年（9 月至次年 8 月）参与多次时，首页提醒核对“只计一次”或“分别计分”；选择分别计分需填写每次确认分数。同学年、同维度的同名独立条目也会提醒核对。确认记录保存在本机，未发生变化时不再提醒；新增、替换或修改相关参与后重新提醒，也可随时从首页的“查看重复核对记录”回看修改。
- 当前记录界面可按维度筛选、修改条目、删除条目，以及查看每次参与的证明。点“导出 Excel”可选择保存位置，生成总表加六个领域工作表的 `.xlsx`；保存成功后自动打开 Android 系统分享面板，可选择已安装的分享应用。
- 在某次参与记录里点“分享活动包”，可勾选要共享的照片，生成 ZIP 并通过系统分享面板发给同学。活动包包含这一项活动的名称、维度、日期、说明、参考估分及选中的照片，不包含班委的职务、学年成绩或其他记录。
- 同学可在“当前记录”点“导入班级活动包”，或从支持的聊天/文件应用用本 App 打开 ZIP。导入前会预览活动和照片，要求确认自己参加，可填写个人职务及参考估分，并选择要保存的照片；确认后才写入本机记录与证明图片。同一活动包再次导入会提示已导入，同名同日期的已有记录也会提示核对。
- 历史评分界面可导入一份本地 `.xlsx` 或逗号分隔的 `.csv`，勾选多个分类工作表，共用表头行和列映射，将原表列映射到活动名称、所属维度、参考分数，以及可选的职务/等级和小分类。其他工作表按列名核对（允许列顺序不同）；映射会保存在手机上供同格式表格复用。
- 导入前逐表显示有效、异常和空表情况。异常分数可点选原文提取的数字（如“单次0.5”可选 0.5，“成员2，负责人3”可选 2 或 3），也可手动输入非负有限数值并点“使用此分数并保留”；没有数字或空分也可手填，允许 0 和小数。候选不自动采用。原文、工作表和行号保留；可撤销保留。修正后重新检查同分重复及异分冲突，修改分数会清除旧冲突选择及跳过确认。剩余异常须明确确认跳过。相同维度、小分类、活动名和身份的同分记录合并并保留全部来源；不同分数逐组选择一个分数或排除整组。确认后一次性替换历史评分库，不修改个人活动和参考分数。旧库已有的未确认变体仍可查看。
- 新建或修改活动时，名称至少输入两个字后，名称下方直接显示历史相似活动，无需展开可选信息；编辑已有活动也可按当前名称查看推荐。选中活动会展开参考信息，再点职务/等级带入历史参考分数；仍可手动调整，未选择候选时不改写原有信息。当前检索是本地文字匹配，不使用网络或语义模型。
- “录入学年成绩”可按学年保存学生自评、同学互评、辅导员/班主任评议、扣分、逐门课程的学分与百分制成绩、体测及健步跑成绩。专业素质按课程学分加权平均，综合成绩按基本素质 × 10% + 专业素质 × 70% + 发展素质 × 20% 测算。

同一条目在同一学年参加多次时，“只计一次”采用条目参考分，“分别计分”采用确认后的逐次分数；未确认前暂不生成综合成绩。各领域活动分按上限封顶，身心健康另加体测的 20% 与健步跑的 10%。图片复制到 App 私有目录，因此从相册原位置移走后仍可查看。

仍有重复待核对、活动参考分缺失、基本素质输入缺失、课程未录入或体测/健步跑未填写时，首页显示“待完善”，不会把不完整的数值当成完整综合成绩。历史参考估分另行保留展示，不会被自动改写。学校实际认定分数仍以校方核算为准。

## 导入说明与边界

班级活动包须由本 App 的“分享活动包”功能生成；普通照片 ZIP 缺少活动信息，不能直接当活动包导入。单次最多分享 30 张照片，单张不超过 30 MB，照片总量不超过 200 MB。接收时允许取消或只保存其中部分照片。活动包导入与下述历史评分表导入是两个独立功能。

在“历史评分”点“导入本地 Excel / CSV”。默认尝试识别常见旧表头；若学校更改列名，请在映射界面手动指定列。活动名称、所属维度、参考分数是必需字段；建议同时映射职务/获奖等级，否则无法区分演员与观众等不同分数。选中工作表共用表头行号，分类取自表内映射列，sheet 名用于来源定位；隐藏表会标记，空表在检查结果中显示。缺少或重复映射列名会阻止导入，需修改源表、调整共用映射或取消勾选问题表。仅分数异常的行可以在预览内指定分数；空活动名、空分类、CSV 多余列等结构问题须修改源文件或确认跳过。逗号小数、千位分隔、负数及溢出数不会作为候选，须核对后手动指定。每张表最多 20000 行，所选表总计最多 100000 行；修改选择或映射、重建页面后，必须重新检查和确认异常分数及冲突，预览中的手动分数不会跨重建保留。数据库自动升级到 v6；新备份保留来源信息，仍可恢复 v5 旧备份（旧来源只保留原行号）。若 Excel 里的分数是公式，文件需包含已经计算并保存的结果；App 不执行公式。暂不支持旧版 `.xls`、在线共享链接、跨行/非表格布局的自动理解。

历史分类若不在 App 的六维列表中，选择推荐活动后须手动指定对应维度。导入表格只用作往年参考，不代表当年的最终评分。

## 导出说明

“总表”按六个领域排列，领域单元格按该领域的活动行数合并；领域内序号从 1 开始。活动名、职务/获奖等级、参考估分分别写入 C、D、E 列，未填写的估分保留为空。其余六张工作表按相同序号列出每项活动的全部凭证照片，一格一张；没有凭证的活动仍保留序号行。照片内嵌为 Excel 的“置于单元格内”图片，不依赖外部链接。照片按参与日期从新到旧、同次参与按添加顺序排列。JPG、PNG 凭证保留原图；其他图片格式转换为最长边不超过 3200 像素的 JPEG。

总表另有隐藏的 F 列“条目ID”，供电脑端核对工具在重新排序或再次导出后识别同一条活动；原有 A–E 列展示不变。旧版导出没有这一列时，电脑端以“领域＋序号”在该次导出内关联凭证。

该图片格式以支持“置于单元格内”功能的 Microsoft 365 / Excel 2024 为目标。WPS 的实际显示需在目标版本上另行验收。当前环境已检查生成文件的结构，但尚未完成 Excel 图形界面的打开验收。

## 成绩测算说明

班级评议 = 自评 × 10% + 同学互评 × 70% + 辅导员/班主任评议 × 20%；基本素质 = 班级评议 − 扣分。专业素质 = Σ（课程学分 × 百分制成绩）/ Σ学分。发展素质 = 体测 × 20% + 健步跑 × 10% + 身心健康活动分（最高 10）+ 其余五类活动分（合计最高 60）。综合成绩 = 基本素质 × 10% + 专业素质 × 70% + 发展素质 × 20%。没有额外假定扣分后的最低分；如学校有更具体的折算、课程筛选或舍入规则，需要按正式规则再调整。
